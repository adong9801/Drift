# Type Along

A browser extension for typing out text you already have. Paste it into the
popup and press Start; in any text box, the next words then show in grey
where you type, and your place moves on as you type them.

- A wrong key shows in red (⌫ and how many) until you delete it, unless
  "Wait for the right key" is off.
- Curly quotes, long dashes and hard spaces in the pasted text are typed with
  the plain keys.
- Works in plain text boxes, rich text editors (including ones inside an
  iframe, such as Canvas's) and Google Docs, which draws its own text: there
  the grey words follow Docs' own cursor.
- The pill in the corner shows how far along you are, with Pause and Stop.

It only watches your keys. What you type goes to the page as normal.

## Install

In Drift: the extensions button → **+** → **Choose File…**, and pick this
folder. In Chrome: `chrome://extensions` → Developer mode → **Load unpacked**.
